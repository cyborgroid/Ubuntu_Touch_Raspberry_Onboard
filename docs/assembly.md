## 1단계: SD 카드 만들기

Raspberry Pi Imager를 설치하고 "Use custom"으로 `cyborgroid-pi5-*.img.xz`를 골라 SD 카드에 굽습니다.

## 2단계: 모니터로 켜 보기

1. 파이에 SD 카드, 모니터, 키보드를 연결하고 전원 어댑터를 마지막에 꽂습니다.
2. 첫 부팅은 몇 분 걸립니다. 일반 Ubuntu 화면이 뜨면 터미널을 엽니다.
3. 기기마다 다른 초기 비밀번호를 확인하고 바꿉니다.

   ```bash
   cat ~/initial-password.txt
   passwd
   rm ~/initial-password.txt
   ```

## 3단계: 화면에 조립하기

전원을 완전히 끄고 작업합니다. 자세한 사진은 [공식 설명서](https://www.raspberrypi.com/documentation/accessories/touch-display-2.html)를 따르세요.

1. 파이의 SoC(가장 큰 칩)에 방열판을 붙입니다.
2. 납작한 케이블(FFC)의 큰 쪽(15핀)을 화면에, 작은 쪽(22핀)을 파이에 꽂습니다.
3. 전원선을 파이의 GPIO 핀에 꽂습니다. **빨강은 2번 핀(5V), 검정은 6번 핀(GND)입니다.** 바꿔 꽂으면 고장 날 수 있으니 다시 확인하세요.
4. 파이를 화면 뒷면 네 모서리 기둥에 맞추고 M2.5 나사 4개로 고정합니다.
5. 전원을 넣으면 터치 홈 화면이 떠야 합니다.

HDMI 모니터를 꽂으면 일반 Ubuntu 화면으로, 뽑으면 터치 홈 화면으로 바뀝니다. 바뀔 때 열려 있던 앱은 닫힙니다.

## 4단계: 기능 확인

- **발열:** 파이와 화면 사이 공간이 좁아 공기가 잘 안 통할 수 있습니다. 터미널에서 부하를 걸어 온도를 확인합니다. `vcgencmd get_throttled`가 `0x0`이면 정상입니다.

  ```bash
  for i in 1 2 3 4; do timeout 600 yes >/dev/null & done
  watch -n 10 vcgencmd measure_temp
  ```

- **Wi-Fi:** 홈 화면의 Wi-Fi 아이콘이나 Ubuntu 설정에서 연결합니다.
- **소리와 통화:** USB 오디오를 꽂아 확인합니다. Pi 5에는 이어폰 잭이 없습니다.

## VPN (선택)

WireGuard 서버를 직접 준비한 경우에만 합니다. 다른 컴퓨터에서 SD 카드의 부트 파티션을 열어 `cyborgroid/wg0.conf`를 넣고 부팅하면, 파일이 시스템으로 옮겨지고 킬스위치가 켜집니다.

```ini
[Interface]
PrivateKey = <이 기기의 개인키>
Address = 10.0.0.2/24
DNS = 10.0.0.1

[Peer]
PublicKey = <서버 공개키>
Endpoint = 203.0.113.10:51820
AllowedIPs = 0.0.0.0/0, ::/0
PersistentKeepalive = 25
```

- `Endpoint`는 도메인이 아니라 IP 주소여야 합니다.
- 킬스위치가 켜지면 VPN이 끊길 때 인터넷도 끊깁니다. 호텔이나 카페의 로그인 페이지도 열리지 않습니다.
- 끄기: `sudo /usr/lib/cyborgroid/wireguard-killswitch.sh down`. 재부팅 후에도 끄려면 `/etc/wireguard/wg0.conf`를 다른 곳으로 옮깁니다.

## 들고 다니기

외장 USB-C 보조배터리를 연결해 씁니다. 5 V 3 A 출력이면 동작하지만 경고가 뜰 수 있고 USB 전류가 600 mA로 제한됩니다. 내장 배터리는 소비전력을 측정한 뒤에 생각합니다. 리튬 셀을 직접 납땜하지 마세요.

- HDMI를 꽂고 뺄 때의 전환
