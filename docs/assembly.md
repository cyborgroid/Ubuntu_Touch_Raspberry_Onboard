# 설치와 조립

기판은 Raspberry Pi 5로 정했고, 맞춤 케이스는 아직 설계 전입니다([hardware.md](hardware.md)). 아래는 케이스 없이 책상 위에서 먼저 켜 보는 순서입니다.

## 공통으로 필요한 것

2026년 11월 3일 기준입니다. 라즈베리파이는 올해 메모리 값 때문에 가격이 여러 번 올랐으니 구매 직전에 다시 확인하세요.

| 부품 | 가격 | 근거 |
|---|---|---|
| Raspberry Pi 5 4GB | 약 204,600원 | 디바이스마트 186,000원 + 부가세 |
| Raspberry Pi 5 8GB | 약 322,300원 | 디바이스마트 |
| 공식 27W USB-C 전원 어댑터 | 18,040원 | 디바이스마트 |
| microSD 64GB (A2 등급) | 약 15,000–30,000원 | 어림값 |
| micro-HDMI → HDMI 케이블 | 약 5,000–15,000원 | 어림값 |
| USB 키보드 | 약 10,000–20,000원 | 어림값 |
| USB 오디오 어댑터 (마이크 지원) | 약 10,000–20,000원 | 어림값 |

메모리는 나중에 늘릴 수 없습니다. 일반 Ubuntu 화면은 시험에서 약 2.2GB를 쓰므로 4GB로 시작할 수 있지만, 브라우저를 많이 쓴다면 8GB가 편합니다. 터치 화면은 Waveshare 4inch DSI LCD를 1순위로 권합니다(제조사 $49.99, 해외 구매). 맞춤 케이스 비용은 설계 후에 알 수 있습니다.

## 1단계: SD 카드 만들기

Raspberry Pi Imager를 설치하고 "Use custom"으로 `cyborgroid-pi5-*.img.xz`를 골라 SD 카드에 굽습니다. 파일의 `.sha256`으로 체크섬을 확인할 수 있습니다.

## 2단계: 모니터로 켜 보기

1. 파이에 SD 카드, 모니터, 키보드를 연결하고 전원 어댑터를 마지막에 꽂습니다.
2. 첫 부팅은 몇 분 걸립니다.
3. Ubuntu 첫 설정 화면에서 언어, 키보드, 계정, 비밀번호를 정합니다. 기본 비밀번호는 없습니다.
4. 모니터가 연결되어 있으므로 일반 Ubuntu 화면이 나옵니다.

## 3단계: 터치 화면 연결

전원을 완전히 끄고 작업합니다. 화면 제조사의 Pi 5 연결 안내를 따르세요.

공식 Touch Display 2라면 설정이 필요 없습니다. Waveshare 패널이라면 `/boot/firmware/config.txt`의 `[pi5]` 아래에 제조사가 안내하는 오버레이를 넣습니다. 4inch DSI LCD는 `dtoverlay=vc4-kms-dsi-waveshare-panel,4_0_inch`이고, 이 값은 공식 이미지의 `overlays/README`에서 확인했습니다. 부트 파티션은 다른 컴퓨터에서도 고칠 수 있습니다.

모니터를 뽑고 켜면 터치 홈 화면이 떠야 합니다.

| 조작 | 동작 |
|---|---|
| 아이콘 터치 | 앱 열기 |
| `Ubuntu` 아이콘 | 설치된 모든 앱 |
| `토큰` 아이콘 | 대시보드와 레이더 |
| 지문 아이콘 | 화면 잠금 (센서는 없습니다) |
| 왼쪽 가장자리에서 밀기 | 앱 독 |
| 오른쪽 가장자리에서 밀기 | 열린 앱 목록 |
| 위쪽 가장자리에서 밀기 | 빠른 설정 (Wi-Fi, 소리, 전원 등) |
| 입력란 터치 | 화면 키보드 |

HDMI 모니터를 꽂으면 일반 Ubuntu 화면으로, 뽑으면 터치 홈 화면으로 바뀝니다. 열린 앱은 닫히지 않습니다.

## 4단계: 기능 확인

- **발열:** 터미널에서 부하를 걸어 온도를 봅니다. `vcgencmd get_throttled`가 `0x0`이면 정상입니다.

  ```bash
  for i in 1 2 3 4; do timeout 600 yes >/dev/null & done
  watch -n 10 vcgencmd measure_temp
  ```

- **Wi-Fi:** 홈 화면의 `네트워크` 아이콘에서 연결합니다.
- **소리:** USB 오디오를 꽂아 확인합니다.
- **통화:** 홈 화면의 `전화` 아이콘은 GNOME Calls입니다. 모뎀이 없으므로 인터넷 전화(SIP) 계정을 넣어야 걸 수 있습니다.

## VPN (선택)

WireGuard 서버를 직접 준비한 경우에만 합니다. 다른 컴퓨터에서 SD 카드의 부트 파티션을 열어 `cyborgroid/wg0.conf`를 넣고 부팅하면, 파일이 시스템으로 옮겨지고 킬스위치가 켜집니다.

```ini
[Interface]
PrivateKey = <이 기기의 개인키>
Address = 10.0.0.2/24
DNS = 10.0.0.1

[Peer]
PublicKey = <서버 공개키>
Endpoint = 203.0.113.10:51820
AllowedIPs = 0.0.0.0/0, ::/0
PersistentKeepalive = 25
```

- `Endpoint`는 도메인이 아니라 IP 주소여야 합니다.
- 킬스위치가 켜지면 VPN이 끊길 때 인터넷도 끊깁니다. 호텔이나 카페의 로그인 페이지도 열리지 않습니다.
- 끄기: `sudo /usr/lib/cyborgroid/wireguard-killswitch.sh down`. 재부팅 후에도 끄려면 `/etc/wireguard/wg0.conf`를 다른 곳으로 옮깁니다.

## 들고 다니기

외장 USB-C 보조배터리를 연결해 씁니다. 5 V 3 A 출력이면 동작하지만 경고가 뜰 수 있고 USB 전류가 600 mA로 제한됩니다. After 디자인에는 내장 배터리 공간이 없습니다. 리튬 셀을 직접 납땜하지 마세요.

## 실물에서 처음 확인할 항목

- 실제 Pi 5 펌웨어로 부팅
- 터치 화면 인식, 터치 방향, 글자 크기
- 실제 터치 패널에서의 가장자리 밀기
- 실제 GPU에서의 화면 동작과 속도
- HDMI를 꽂고 뺄 때의 전환
- 실제 Wi-Fi 스캔과 레이더, 소리, 발열
