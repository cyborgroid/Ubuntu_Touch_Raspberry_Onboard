# 현재 상태

2026년 11월 3일 기준입니다. **아직 실제 라즈베리파이에서 켜 본 적이 없습니다.** 아래 "확인됨"은 모두 PC 안에서 공식 Ubuntu 26.04 Desktop for Raspberry Pi 기반 이미지를 가상 기기(QEMU)로 부팅하거나, 같은 버전의 GNOME을 컨테이너에서 실행해 확인한 결과입니다.

## 구조

표준 Ubuntu에 GNOME 확장 기능 하나(`cyborgroid-touch`)를 더한 것입니다. 앱, 첫 설정, 로그인, 화면 잠금, 화면 키보드, 한글 입력, 업데이트는 모두 Ubuntu 표준 기능을 그대로 씁니다. 정품 Ubuntu Touch나 Lomiri는 들어 있지 않습니다.

## 확인됨

| 기능 | 어떻게 확인했나 |
|---|---|
| After 디자인의 홈 화면 (세로 격자, 배터리 위젯, 페이지 점, 지문 아이콘) | 이미지 부팅 후 화면 캡처 |
| Ubuntu 표준 첫 설정 화면 | 새로 구운 상태와 같은 조건으로 부팅 |
| 아이콘으로 앱 열기: 메모, 전화, 파일, 문서, 네트워크, 동영상, 토큰, 브라우저, 전체 앱 | 가상 기기에서 가상 태블릿으로 클릭 |
| 터치로 앱 열기, 왼쪽·오른쪽·위쪽 가장자리 밀기 | GNOME 컨테이너에서 가상 터치 입력 |
| 일반 Ubuntu로 전환하고 복귀, 열린 앱 유지 | 전환 설정으로 시험 (가상 기기에 HDMI가 없음) |
| 표준 화면 키보드의 한글 글자판, 터치 입력의 한글 조합 | 메모 앱에서 입력, 화면 캡처 |
| 물리 키보드 한글 입력 | 메모 앱과 Firefox에서 `한글` 조합 확인 |
| 지문 아이콘으로 화면 잠금 | 잠김 상태와 화면 꺼짐 확인 |
| 시스템 파일을 사용자 계정으로 고칠 수 없음 | 부팅한 이미지에서 권한 검사 |
| 킬스위치: VPN 밖으로 나가는 통신 차단 | 실제 패킷과 WireGuard 터널 시험 29개, VPN 설정을 넣은 부팅 |
| 코어 엔진 | 단위 테스트 16개, 노트북의 실제 Wi-Fi로 실행 |
| 메모리 사용량 | 터치 화면에서 약 1.8–2.1GB, 일반 Ubuntu 약 2.2GB |

## 실제 기기에서 처음 확인할 것

- Pi 5 펌웨어로 실제 부팅
- 실제 터치 패널의 인식, 방향, 글자 크기, 가장자리 밀기
- 실제 GPU에서의 화면 동작과 속도
- HDMI를 꽂고 뺄 때의 자동 전환
- 실제 Wi-Fi 스캔과 레이더 (가상 기기에 Wi-Fi 칩이 없어 오류로 표시됨)
- 소리, 인터넷 전화 통화, 발열

## 아직 안 되거나 불편한 것

| 항목 | 현재 상태 |
|---|---|
| 맞춤 케이스 | 기판은 Pi 5로 정했고, After 모습의 케이스는 아직 설계 전입니다. [hardware.md](hardware.md) 참고 |
| 전화 | GNOME Calls가 열리지만 모뎀이 없어 인터넷 전화(SIP) 계정이 필요합니다. 계정을 넣은 통화는 시험하지 않았습니다. 시험 중 백그라운드 서비스(`calls-daemon`)가 시작에 실패한 기록이 있습니다 |
| 설정 아이콘 | 시험에서 앞서 연 네트워크 화면이 그대로 나왔습니다. 다른 항목을 보려면 뒤로 가야 합니다 |
| 페이지 점 | After 디자인대로 3개를 표시하지만 페이지는 하나입니다 |
| 지문 아이콘 | 센서가 없어 누르면 화면을 잠그기만 합니다 |
| 배터리 표시 | 잔량 측정 부품이 없으면 `--`로 표시합니다 |
| 화면 크기 조정 | 480×640과 720×1280에서 배치를 확인했습니다. 실제 패널의 확대 배율은 정해야 합니다 |

## 사양서와 다른 점

원래 구상([아키텍처 사양서](../raspberry_pi_5_touchphone_desktop_architecture.md))을 그대로 구현할 수 없거나, 더 쉬운 방법으로 바꾼 부분입니다.

| 사양서 | 실제 | 이유 |
|---|---|---|
| 통신비 0원, 국경 없는 통신 | Wi-Fi 등 인터넷 연결이 따로 있어야 하고, VPN 서버도 직접 준비해야 합니다 | 기기에 모뎀이 없고, 서버와 회선 비용은 없앨 수 없습니다 |
| 무상 음성 통화 | 인터넷 전화 계정이 필요합니다. 일반 전화번호로 걸려면 유료 중계 서비스가 필요합니다 | 일반 전화망은 통신사를 거칩니다 |
| 데이터 토큰 채굴 | 이 기기 안에만 저장되는 사용량 기록입니다 | 블록체인이나 거래소와 연결되지 않으며 **금전 가치가 없습니다.** 앱에도 그렇게 표시합니다 |
| 와이파이 공간 인지 | 주변 공유기 수, 신호 세기, 이동 여부만 추정합니다 | 신호 세기로는 방향을 알 수 없습니다. 레이더의 점 각도는 실제 방향이 아닙니다 |
| 완벽한 익명성 | VPN 서버 운영자는 접속 기록을 볼 수 있습니다 | WireGuard는 익명 서비스가 아니라 암호화 터널입니다 |
| 하드웨어 킬스위치 | 소프트웨어 방화벽입니다. 파일 이름만 사양서를 따랐습니다 | 스위치 부품이 없습니다. IPv6 유출, 공용 Wi-Fi 노출 등 사양서 스크립트의 구멍을 막았습니다 |
| VMware 기반 Ubuntu Touch 통신 노드 | 만들지 않았습니다 | Pi 5에서 VMware를 쓸 수 없고, 호환성 면에서 표준 Ubuntu가 낫습니다 |
| 전용 Avalonia 터치 화면 | 대시보드와 레이더 앱으로 남겼고, 터치 화면은 GNOME 확장이 맡습니다 | 표준 Ubuntu 앱과 호환하기 위해서입니다 |
| 외부 모니터와 키보드 연결 시 전환 | 모니터만 연결해도 전환합니다 | 제품 방향 변경에 따랐습니다 |
| 4–7인치 화면, SMA 안테나, 내장 배터리 | 4인치 화면 권장, 내장 안테나, 배터리 없음 | After 디자인을 따랐습니다. [hardware.md](hardware.md) 참고 |

이름은 [Brand_Naming.md](../Brand_Naming.md)의 종합 의견대로 **Cyborgroid**를 썼습니다.
