# 현재 상태

2026년 11월 3일 기준입니다. **아직 실제 라즈베리파이에서 켜 본 적이 없습니다.** 아래 "확인됨"은 모두 컴퓨터 안의 가상 기기와 노트북에서 확인한 결과입니다.

## 확인됨

| 기능 | 어떻게 확인했나 |
|---|---|
| 첫 부팅 (파티션 확장, 기기별 비밀번호, SSH 키 생성) | 가상 기기 부팅 |
| 터치 홈 화면과 하단 메뉴 | 가상 기기 화면 캡처 |
| 아이콘을 눌러 앱 열기: 계산기, Wi-Fi 설정, 시스템 설정, Firefox | 가상 입력으로 실제 탭 |
| 하단 메뉴로 앱 닫기, 홈으로 돌아가기, 화면 키보드 열기 | 가상 입력으로 실제 탭 |
| 일반 Ubuntu 화면으로 전환하고 복귀 | 전환 명령으로 시험 (가상 기기에 HDMI가 없음) |
| 시스템 파일을 사용자 계정으로 고칠 수 없음 | 가상 기기에서 권한 검사 |
| 킬스위치: VPN 밖으로 나가는 통신 차단 | 실제 패킷과 WireGuard 터널로 시험 29개, 가상 기기 부팅 시험 |
| 코어 엔진: 트래픽 기록, 모드 감지, 저장 | 단위 테스트 15개, 노트북에서 실행 |
| 메모리 사용량 | 터치 화면 약 1.1GB, 일반 Ubuntu 약 2.2GB |

## 실제 기기에서 처음 확인할 것

- Pi 5 펌웨어로 실제 부팅
- 공식 터치 화면의 자동 인식, 터치 방향, 글자 크기
- 실제 GPU에서의 화면 동작과 속도
- HDMI를 꽂고 뺄 때의 자동 전환
- 실제 Wi-Fi 스캔과 레이더 (가상 기기에 Wi-Fi 칩이 없어 레이더는 데이터 없이 표시됨)
- 소리와 통화
- 발열

## 아직 안 되거나 불편한 것

| 항목 | 현재 상태 |
|---|---|
| 전화 | 전용 화면이 없습니다. 전화 아이콘을 누르면 터미널에서 `baresip`이 열립니다. |
| Wi-Fi 설정 | 터미널 화면인 `nmtui`로 열려 터치로 쓰기 불편합니다. 설정 아이콘의 네트워크 화면을 쓸 수도 있습니다. |
| 화면 키보드 | 영어 등만 있고 **한글 배열이 없습니다.** 한글은 일반 Ubuntu 화면에서 USB 키보드로 입력합니다. |
| 화면 잠금 | 없습니다. Ubuntu 로그인 화면(GDM)을 쓰지 않아서 일반 Ubuntu에서도 잠기지 않고, 켜면 바로 사용할 수 있습니다. |
| 모드 전환 | 전환하면 열려 있던 앱이 닫힙니다. |
| 메시지 | 없습니다. |
| 배터리 표시 | 잔량 측정 부품이 없어 `--`로 표시됩니다. |
| 시스템 설정 앱 | GNOME 전용 앱이라 터치 화면에서는 일부 기능이 동작하지 않을 수 있습니다. |

## 사양서와 다른 점

원래 구상([아키텍처 사양서](../raspberry_pi_5_touchphone_desktop_architecture.md))을 그대로 구현할 수 없거나, 더 쉬운 방법으로 바꾼 부분입니다.

| 사양서 | 실제 | 이유 |
|---|---|---|
| 통신비 0원, 국경 없는 통신 | Wi-Fi 등 인터넷 연결이 따로 있어야 하고, VPN 서버도 직접 준비해야 합니다. | 기기에 모뎀이 없고, 서버와 회선 비용은 없앨 수 없습니다. |
| 무상 음성 통화 | VPN으로 연결된 기기끼리만 통화합니다. 일반 전화번호로는 걸 수 없습니다. | 일반 전화망에 연결하려면 통신사나 유료 중계 서비스가 필요합니다. |
| 데이터 토큰 채굴 | 이 기기 안에만 저장되는 사용량 기록입니다. | 블록체인이나 거래소와 연결되지 않으며 **금전 가치가 없습니다.** 앱에도 그렇게 표시합니다. |
| 와이파이 공간 인지 | 주변 공유기 수, 신호 세기, 이동 여부만 추정합니다. | 신호 세기로는 방향을 알 수 없습니다. 레이더의 점 각도는 실제 방향이 아닙니다. |
| 완벽한 익명성 | VPN 서버 운영자는 접속 기록을 볼 수 있습니다. | WireGuard는 익명 서비스가 아니라 암호화 터널입니다. |
| 하드웨어 킬스위치 | 소프트웨어 방화벽입니다. 파일 이름만 사양서를 따랐습니다. | 스위치 부품이 없습니다. IPv6 유출, 공용 Wi-Fi 노출 등 사양서 스크립트의 구멍을 막았습니다. |
| VMware 기반 Ubuntu Touch 통신 노드 | 만들지 않았습니다. | VMware는 Pi 5에서 쓸 수 없고, 통화와 VPN은 가상 머신 없이 동작합니다. |
| Ubuntu Touch | 비슷하게 디자인한 화면입니다. | Pi 5용 공식 Ubuntu Touch가 없습니다. |
| 외부 모니터와 키보드 연결 시 전환 | 모니터만 연결해도 전환합니다. | 제품 방향 변경에 따랐습니다. |
| 4–7인치 화면과 SMA 안테나 | 공식 5인치 화면과 내장 안테나를 씁니다. | 쉽게 살 수 있는 부품을 우선했습니다. |
